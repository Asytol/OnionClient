# Onion Client
## The Minimal, Manual irc client

This is one of the simplest and most annoying irc clients out there. It was made as a way to get an opinion on the irc protocol.

### How do I use this?
It is simple. Compile it. Execute it and then follow the basic instructions it gives you. To send a message you do a `PRIVMSG #[channel] : <Message here>`
